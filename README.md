# House Price Prediction — Machine Learning Project

## 📌 About

This project predicts **house prices** using Machine Learning techniques. It applies concepts from the **Data Science Handbook**, including data preprocessing, feature engineering, model training, and evaluation.

## 🛠️ Tech Stack

* Python
* NumPy
* Pandas
* Matplotlib
* Scikit-learn
* Jupyter Notebook

## 🔄 Workflow


Dataset
   ↓
Data Understanding
   ↓
Data Cleaning
   ↓
Data Preprocessing
   ↓
Feature Engineering
   ↓
Model Training
   ↓
Model Evaluation
   ↓
House Price Prediction


## 📚 Concepts Used

* Data Preprocessing
* Handling Missing Values
* Feature Engineering
* Exploratory Data Analysis (EDA)
* Data Visualization
* Train-Test Split
* Feature Scaling
* Machine Learning
* Regression
* Model Evaluation

## 🤖 Machine Learning

The project uses **Regression** to predict the price of a house based on its features.

The model is trained using the training dataset and evaluated on unseen test data.

## 🎯 Objective

To build a Machine Learning model that can learn from existing housing data and predict the price of new houses.

## 📂 Project Structure

* `House-Price-Prediction/` → Main project folder
* `data/` → Contains dataset files
* `notebook/` → Jupyter notebooks for analysis and model building
* `README.md` → Project documentation
* `requirements.txt` → List of required Python libraries

## 🚀 How to Run

* Install dependencies using:

  pip install -r requirements.txt
  
* Launch Jupyter Notebook:
  
  jupyter notebook
 
* Open the project notebook
* Run all cells step by step to execute the project
